TASKFLOW - EASY TO OPEN VERSION

HOW TO OPEN
1. Extract this ZIP file.
2. Open the TaskFlow_Easy_Run folder.
3. Double-click index.html.
4. It opens directly in Chrome. No Python, Maven, or server setup is needed.

FEATURES
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks completed / reopen
- Filter All, Pending, Completed
- Due dates and descriptions
- Responsive layout
- Saves task data in this browser using localStorage

IMPORTANT PROJECT LIMITATION
This is a browser-only frontend demo, NOT a full-stack application.
The name/login screen is a local demo profile, not secure authentication.
Data is stored in the browser and there is no server, REST API, or shared database.
Use this version to preview and test the interface easily. If the internship requires
full-stack authentication and database functionality, the Flask full-stack version
or a deployed backend is still required.
